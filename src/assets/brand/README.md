# Brand marks

Exported from the mockup canvas (Identity board). Colours come from the theme tokens when the SVG is inlined; the hex fallbacks are the Observatory (dark) values, used when a file is loaded as an image.

| File                  | Use                                                 | Status                                  |
| --------------------- | --------------------------------------------------- | --------------------------------------- |
| `mark-compact.svg`    | Header mark (next to the wordmark), 32 px and up    | Draft, pending the logo-redraw sign-off |
| `mark-compact-16.svg` | Favicon and anything under 24 px; tail loop dropped | Draft, pending the logo-redraw sign-off |
| `mark-full.svg`       | Flat redraw of the original logo, large placements  | Direction only, not final artwork       |

The original raster logo stays the Substack avatar and the social-post image. It is not used on the site.

The wordmark is live text, not an image: "Data" in `--color-link` and "Virgo" in `--color-text`, set in `--font-serif` at weight 500.
