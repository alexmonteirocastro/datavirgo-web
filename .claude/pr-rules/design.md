# Design rules

- Tokens come from ADR-0001; add a token before using a new value.
- Dark = Observatory, light = Paper. Both must be defined for every new colour token.
- Fonts: EB Garamond, IBM Plex Sans, IBM Plex Mono only. Provide fallback stacks.
- Glyphs are inline SVG from the DataVirgo set; no icon fonts or libraries.
- Wheel conventions: retrograde red + ℞; hard aspects dashed orange, soft solid blue;
  structure lines at 55%; clusters of 3+ use the inner ring with leader lines.
- Compare against the mockup canvas; list deviations explicitly.
